# NYU Abu Dhabi Core Bioinformatics

We support bioinformatics research through a collection of projects, tools, and computational workflows. This GitHub organization brings those projects together so researchers and collaborators can discover the code, understand how it is used, and build on it.

## Our work

Our repositories support bioinformatics across multiple research projects. Depending on the project, they may include analysis workflows, reusable scripts, software, or supporting documentation. Each repository has its own scope and should be treated as the authoritative source for its methods, requirements, and usage instructions.

## Explore our projects

Browse the repositories in this organization to find a project. Start with the repository README for its overview, installation instructions, examples, and project-specific guidance. If you are looking for a particular analysis or tool, check the repository topics and descriptions as well.

## Reproducibility and collaboration

We aim to make project code understandable and reusable. When working with a repository, please:

- Follow its README and any project-specific contribution guidance.
- Cite the associated publication, software, or project documentation when using its methods or code.
- Include the relevant version, release, or commit when describing a computational analysis.
- Open an issue in the relevant repository for questions, bug reports, or feature requests.
- Do not commit sensitive, identifiable, or access-restricted data. Check the repository's guidance and your project requirements before sharing data or results.

## Contributing

Contributions and collaboration are welcome. Before opening a pull request, check the relevant repository for contribution instructions, licensing, and any project-specific requirements. For broader inquiries, please contact the team through the contact details listed on the relevant project or institutional page.

## Repository guidance

Each project is maintained in its own repository. Please use that repository's documentation for current status, dependencies, supported data, and contact details, as these can differ across projects.
